# 学习乐园（三年级）

给三年级小朋友用的 iPad 学习平台，涵盖 **语文、数学、英语、科学** 四个学科，纯网页应用（PWA），无需安装 App Store、无需服务器后台，数据保存在设备本地。

## 线上地址（iPad 直接访问）

**https://nickforai.github.io/xuexi-le-yuan/**

用 iPad 的 Safari 打开后，点分享 → **添加到主屏幕**，就能像 App 一样全屏使用，支持离线缓存。以后更新：改完代码 `git push` 后等 1-2 分钟即可生效。

## 星星与游戏机会

- 全平台统一用「星星」一种货币：每天打卡 +4 · 口算一轮 +2（全对 +3）· 单词测验 +2（全对 +3）· 科学问答 +2（全对 +3）
- 语文录音背诵：古诗页主按钮就是「🎤 开始背诵」，点后原文遮住凭记忆背，每天每首按最好成绩记一次星星：准确率 <60% 得 0 颗 · ≥60% 得 1 颗 · ≥80% 得 2 颗 · ≥90% 得 3 颗
- 语文生字：1-6 年级各 24 个常用字，点开学拼音、组词和笔顺动画（离线可用）
- 语文阅读：1-6 年级各 2 篇短文，可语音播放；点「开始阅读」边读边识别，读对的字变绿、读错的标红，结束按同款规则（60/80/90）得星星，每篇每天按最好成绩记一次

> ⚠️ 录音识别必须用 **https** 网址打开（即线上地址），浏览器才会允许使用麦克风；局域网 http 方式不支持语音识别，会提示改用安全连接。
- 斗地主：**5 颗星星兑换 1 次机会**；我的世界：**10 颗星星兑换 1 次机会**（两个游戏的机会分开计数）
- 游戏是纯奖励：赢一局开心一下，输掉不扣星星，游戏本身不再发星星，防止"玩游戏无限赚星星"的循环
- 斗地主页面有完整的出牌记录，谁出了什么牌、谁"不要"都看得见；点「提示」会自动选出能压过的牌（要不起时自动不出）
- 我的世界每局不限时；拆方块获得的物品进背包，工作台合成消耗背包材料；斧头砍树、稿子挖石头有加成；建造与背包自动保存在 iPad 本地
- 生存模式：❤️ 生命值 / 🍗 饥饿值（吃苹果、生肉补充）；白天黑夜约 3 分钟一轮，夜晚生成僵尸、骷髅，装备宝剑攻击；🐑 打羊得羊毛，3羊毛+3木板合成床，夜晚睡觉直接到天亮并设置重生点；死亡后回到床边/出生点，背包保留
- 挖矿进阶：地下生成煤/铁/金/钻石（越深越珍贵，钻石需铁镐）；熔炉（8石头合成）用煤作燃料：粗铁+煤→铁锭、生肉+煤→烤肉；铁锭+木棒→铁剑（伤害更高）、铁镐（挖矿翻倍）、铁甲（减伤）
- 村庄与箱子：地图角落有 8 栋房子的小村庄，村民在村里溜达（不能打）；屋里箱子存着食物、水、煤、矿石等，点「👆 使用」打开拿取
- 箱子每日刷新：村庄箱子每天自动重新装满（新的一天进入游戏会有提示），全村总共保证 10-20 颗钻石，拿完了第二天还有
- 村民交换：点一下村民打开交换面板——1 钻石→9 铁锭；3 木板→64 箭或 1 弓；10 木板→2 肉；1 肉→2 弓或 6 木板
- 动物伙伴：🐷 粉色的小猪掉 2 块肉，🐮 棕色的大牛掉 5 块肉，白天会自动补充数量
- 流体与工具：放置的水/岩浆会流动（天然湖泊静止保流畅）；3 铁锭做铁桶，装备后对准水/岩浆点「使用」装桶，倒水浇岩浆→黑曜石、倒岩浆盖水→石头
- 远程武器：弓装备后点「使用」射箭（每次消耗 1 支箭，没了提示"没有可用的箭"）；大炮（20 铁锭）发射炮弹（2 铁锭/颗），爆炸能采矿、打猪牛羊
- 地图：范围扩大到 ±68（面积约 5 倍），树木、矿脉数量同步增加
- 湖泊与地形：开局就有湖泊水域，山丘起伏，地下有洞穴；水可以收集和放置
- 物品更清晰：背包/快捷栏全部改用易懂的 emoji 图标（🌱🪵🪨💧⚔️…）
- 触摸操作：长按方块=挖掉（松开停止）；先点快捷栏选方块，再点一下目标位置=放置；羊是趴着的造型
- 背包交互：🎒 背包按钮在快捷栏最左边；长按背包里的物品可拖出来——拖到快捷栏选中，拖到游戏里放出来（消耗 1 个）

## 在 iPad 上使用（推荐：发布到 GitHub Pages）

用免费的 GitHub Pages 发布后，iPad 上体验最好：有正式网址、可"添加到主屏幕"变成 App 图标、支持离线缓存。

1. 在 [GitHub](https://github.com) 建一个公开仓库（比如 `xuexi-le-yuan`），把这个文件夹里**除 `.git` 外**的所有文件上传进去；
2. 打开仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → 分支选 `main`，保存；
3. 等 1-2 分钟，你会得到一个网址 `https://你的用户名.github.io/xuexi-le-yuan/`；
4. 在 iPad 的 Safari 打开这个网址 → 点分享按钮 → **添加到主屏幕** → 桌面就有"学习乐园"图标了，之后全屏使用、离线可用；
5. 以后改内容：在电脑上改文件再上传，iPad 刷新即可（自动更新的 App 图标版下次打开会自动拿到新版）。

## 在家里测试（局域网方式）

不改任何内容、只想先在 iPad 上试试：

```bash
cd "/Users/nick/Documents/三年级（倪子凡）"
python3 -m http.server 8000
```

更省事：**双击项目里的 `start-server.command`**，它会自动启动服务并显示 iPad 该打开的地址。

然后 iPad 用 Safari 打开 `http://电脑的局域网IP:8000`（Mac 上可到 系统设置 → Wi-Fi → 详细信息 查看 IP，例如 `192.168.0.25`）。注意：这种方式走 http，无法安装主屏幕图标和离线缓存，但全部功能可用；Mac 关机/睡眠后服务会停，重新双击脚本即可。日常用还是建议 GitHub Pages。

## 最省事的测试方式

把 `index.html` 和 `css/`、`js/`、`icons/` 这几个文件夹用隔空投送发到 iPad 的"文件"App，再用 Safari 打开 `index.html` 即可使用（个别功能受限于本地文件方式，长期使用不推荐）。

## 想改内容？

- 古诗、英语单词、科学题：改 `js/data.js`；
- 口算难度与出题规则：改 `js/kousuan.js`；
- 颜色、字体大小等外观：改 `css/style.css`；
- 图标：运行 `python3 scripts/make_icons.py` 重新生成。
