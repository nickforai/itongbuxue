# 学习乐园（三年级）

给三年级小朋友用的 iPad 学习平台，涵盖 **语文、数学、英语、科学** 四个学科，纯网页应用（PWA），无需安装 App Store、无需服务器后台，数据保存在设备本地。

## 现有功能

| 模块 | 内容 |
|---|---|
| 🏠 首页 | 学科入口、每日打卡、连续天数、星星奖励 |
| 📖 语文 | 三年级必背古诗 14 首：点读（语音朗读）+ 背诵打卡 |
| 🔢 数学 | 口算 4 档难度（20 以内加减 → 乘除口算），大按键输入、计时、错题自动收录 |
| 🔤 英语 | PEP 三年级核心词 60+：中英单词卡（点读）+ 看词选义小测验 |
| 🔬 科学 | 教科版主题 6 个：科普阅读（可朗读）+ 3 题小问答 |
| 🃏 斗地主 | 完成作业赚积分，5 积分兑换 1 次机会；和两个机器人打牌，有出牌记录和提示，赢了奖励星星 |
| 👨‍👩‍👧 家长空间 | 一周学习柱状图、星星/打卡统计、错题本、导出/重置数据 |

设计上为触屏优化：大按钮、大字体、纯点选、无键盘输入负担；数据全部存在设备本地（localStorage），不联网也能用。

## 积分与游戏机会

- 完成作业就能赚积分：每天打卡 +1 · 口算一轮 +2（全对 +3）· 背一首诗 +2 · 单词测验 +2（全对 +3）· 科学问答 +2（全对 +3）
- 大厅里用 **5 积分兑换 1 次游戏机会**，进入斗地主开始游戏消耗 1 次机会
- 斗地主每赢一局奖励 1 颗星；输掉不扣积分，防止"玩游戏无限赚积分"的循环
- 斗地主页面有完整的出牌记录，谁出了什么牌、谁"不要"都看得见；点「提示」会自动选出能压过的牌（要不起时自动不出）

## 在 iPad 上使用（推荐：发布到 GitHub Pages）

用免费的 GitHub Pages 发布后，iPad 上体验最好：有正式网址、可"添加到主屏幕"变成 App 图标、支持离线缓存。

1. 在 [GitHub](https://github.com) 建一个公开仓库（比如 `xuexi-le-yuan`），把这个文件夹里**除 `.git` 外**的所有文件上传进去；
2. 打开仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → 分支选 `main`，保存；
3. 等 1-2 分钟，你会得到一个网址 `https://你的用户名.github.io/xuexi-le-yuan/`；
4. 在 iPad 的 Safari 打开这个网址 → 点分享按钮 → **添加到主屏幕** → 桌面就有"学习乐园"图标了，之后全屏使用、离线可用；
5. 以后改内容：在电脑上改文件再上传，iPad 刷新即可（自动更新的 App 图标版下次打开会自动拿到新版）。

## 在家里测试（局域网方式）

不改任何内容、只想先在 iPad 上试试：

```bash
cd "/Users/nick/Documents/三年级（倪子凡）"
python3 -m http.server 8000
```

更省事：**双击项目里的 `start-server.command`**，它会自动启动服务并显示 iPad 该打开的地址。

然后 iPad 用 Safari 打开 `http://电脑的局域网IP:8000`（Mac 上可到 系统设置 → Wi-Fi → 详细信息 查看 IP，例如 `192.168.0.25`）。注意：这种方式走 http，无法安装主屏幕图标和离线缓存，但全部功能可用；Mac 关机/睡眠后服务会停，重新双击脚本即可。日常用还是建议 GitHub Pages。

## 最省事的测试方式

把 `index.html` 和 `css/`、`js/`、`icons/` 这几个文件夹用隔空投送发到 iPad 的"文件"App，再用 Safari 打开 `index.html` 即可使用（个别功能受限于本地文件方式，长期使用不推荐）。

## 数据说明

- 星星、打卡、错题本都存在**当前设备**的浏览器本地存储里，不会上传任何服务器；
- 不要清空 iPad Safari 的"网站数据"，否则记录会丢；
- 家长空间里有「导出学习记录」（复制到剪贴板）和「重置所有数据」。

## 想改内容？

- 古诗、英语单词、科学题：改 `js/data.js`；
- 口算难度与出题规则：改 `js/kousuan.js`；
- 颜色、字体大小等外观：改 `css/style.css`；
- 图标：运行 `python3 scripts/make_icons.py` 重新生成。

## 开发自检

```bash
python3 -m http.server 8642   # 先起本地服务
node scripts/verify.mjs       # 自动检查各页面功能（需要本机 Chrome）
```
