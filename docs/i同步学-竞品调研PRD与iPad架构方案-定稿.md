# 第一部分 市场调研（义务教育 iPad 学习产品）

> 调研视角：教育行业产品架构师视角；目标设备：iPad（支持 Apple Pencil、iPadOS 分屏、手写批注）；范围：国内主流面向义务教育、App Store 正式上架的学习产品；分类：学科同步教辅类、作业工具类、专项能力类、网课体系类、无纸化笔记工具类。

## 一、行业背景前置（架构师视角市场判断）

**硬件差异**：安卓学习机大多深度定制系统、管控更强；iPad 为通用平板，App 无系统级锁屏管控，产品必须依靠软件内青少年模式、应用时长限制实现防沉迷；Apple Pencil 手写生态是核心差异化优势，优秀产品都会深度适配压感、手写识别、PDF 批注。

**产品路线分化**：

| 路线 | 代表 | 定位 |
|---|---|---|
| A 作业刚需工具 | 作业帮、小猿 | 流量入口 = 拍照搜题，主打课后作业场景 |
| B 校内同步体系 | 学而思、纳米盒、洋葱学园 | 依托教研体系，走预习-听课-练习-复习完整闭环 |
| C 专项单科工具 | 英语、口算、古诗文类 | 轻量化、垂直深耕 |
| D 无纸化生产力 | GoodNotes、Notability | 不属于教育厂商自研，但义务教育 iPad 用户普及率极高 |

**行业痛点**：多数 App 的 iPad 端是 iPhone 版简单拉伸，没有原生横屏布局、Apple Pencil 优化差；只有头部产品完成 iPad 原生适配；同时监管持续收紧，拍照搜题功能增加使用时段限制，各大厂商加速向「AI 启发式答疑」转型，弱化直接给答案。

## 二、主流产品清单、核心功能与 iPad 适配情况

### （一）全科作业 & AI 辅导赛道

**1. 作业帮**

- 定位：课后作业辅助工具，全学段全科答疑；义务教育核心用户为小学 4 年级–初中。
- 核心功能：AI 拍照搜题/整页搜题（19 亿题库、手写识别、多解法、知识点溯源、同类举一反三）；AI 秒批作业（口算、选择填空、应用题、英语作文）；AI 伴学答疑（大模型启发式讲解、可追问）；校内同步板块（各版本教材同步课时练习、单元卷、专项训练）；错题系统（按知识点筛选、导出 PDF、定时复习）；直播/录播 + 家长端学情监控与时长管控。
- iPad 适配：有独立 iPad 布局、支持横屏、Apple Pencil 手写作答；短板是界面偏手机移植、分屏体验一般。
- 架构特点：多模态图像识别引擎 + 题库中台 + 用户行为推荐引擎；C 端免费引流，VIP 会员 + 线上课程变现。

**2. 小猿搜题 / 猿辅导**

- 定位：对标作业帮，作业工具 + 体系化网课双主线。
- 核心功能：拍照搜题、整页批改（手写识别较强）；小猿 AI 助教（苏格拉底式提问引导）；真题题库、同步练习、试卷库、自定义组卷；错题本 + 学情诊断（知识薄弱图谱）；专项工具（口算批改、英语听说、作文 AI 批改、古诗文）。
- iPad 适配：原生横屏优化较好，支持 Apple Pencil 答题批注，直播分屏兼容性强。
- 差异化：理科解析质量突出；合规化改造更早，弱化「秒出答案」。

### （二）体系化同步学习赛道

**3. 学而思 App（好未来・九章大模型）**

- 定位：培优体系起家，校内同步 + 能力拓展，小初全科系统学习。
- 核心功能：校内同步学（预习微课、随堂练习、单元检测）；小思 AI 1 对 1（AI 数字人答疑、指尖查词、点选知识点讲解）；分层学情诊断（基础/标准/备考三模式 + 知识图谱）；AI 作文批改、口语分级训练、AI 听写背诵；分级阅读书库；AI 自动生成每日学习任务 + 家长端实时学情报表。
- iPad 适配：深度适配横屏与 Apple Pencil；缺点：完整内容大量依赖 VIP 订阅。

**4. 洋葱学园**

- 定位：理科可视化动画微课，3 年级–初中数理化为主，主打「理解原理，不刷题」。
- 核心功能：5–8 分钟动画微课；AI 自学规划（入学诊断生成个性化路径）；AI 私教答疑（视频中随时提问）；学练闭环（微课+随堂习题+单元测评，错题关联微课片段）；离线下载。
- iPad 适配：横屏原生优化优秀，支持 Pencil 批注；文科资源相对薄弱。

**5. 纳米盒**

- 定位：小学阶段王牌同步工具，主打课本点读，语英刚需，小学 1–6 年级主力。
- 核心功能：正版教材点读（50+ 版本语文英语课本，跟读评测、纠音、复读）；语文工具（生字听写、背诵、古诗文、作文）；数学同步练习、口算专项；AI 口语测评、绘本阅读。
- iPad 适配：横屏点读体验优秀、大屏模拟实体课本、Pencil 课本批注；短板是初中内容薄弱。

### （三）专项单科类产品

- 有道词典/有道少儿英语：单词背诵、课本词库同步、AI 口语跟读、翻译、听力；适合 iPad 分屏查词。
- 西窗烛：古诗文赏析、背诵打卡、诗词默写、文言文注释，免费资源丰富。
- 可汗学院 Kids（海外）：低龄启蒙，数学、阅读逻辑互动课程，全英文/中文、无广告。

### （四）无纸化学习生产力工具

- **GoodNotes 5**：PDF 批注、电子笔记本、试卷图层刷题（一层做题、一层答案隐藏）、Apple Pencil 压感、手写转文字；纸笔体验公认最好。
- **Notability**：录音 + 笔记同步，适合上网课一边听一边记。
- **MarginNote 3**：思维导图 + 文档阅读，适合初中文科梳理知识点框架。

## 三、产品横向对比总表（架构师视角）

| 产品 | 核心场景 | 优势人群 | iPad 原生适配 | 最大短板 | 商业模式 |
|---|---|---|---|---|---|
| 作业帮 | 课后作业答疑、搜题 | 小学高段、初中生 | 中等（横屏、手机 UI 移植） | 广告多，容易依赖搜题 | 免费基础 + VIP 课程 |
| 小猿搜题 | 作业批改、理科答疑 | 初中生 | 良好 | 文科资源一般 | 会员 + 直播课 |
| 学而思 App | 系统同步学习、培优 | 全学段 | 优秀 | 订阅费偏高 | 年度 VIP 为主 |
| 洋葱学园 | 数理化原理理解 | 理科薄弱学生 | 优秀 | 文科资源少 | 课程订阅 |
| 纳米盒 | 小学课本点读 | 小学 1–6 年级 | 优秀 | 初中内容匮乏 | 会员解锁教材音频 |
| GoodNotes | 无纸化刷题、笔记 | 全部学段 | 极佳 | 无题库课程，纯工具 | 一次性买断 |

## 四、市场分析

1. **市场格局**：义务教育学习产品呈「两超（作业帮、小猿）+ 多强（学而思、洋葱、纳米盒）+ 长尾工具」格局；流量入口在作业场景，留存靠同步课程与错题闭环。
2. **iPad 平台独有的产品机会与现存短板**：
   - 绝大多数产品 iPad 适配不彻底（iPhone 拉伸、Pencil 支持弱、分屏差）；
   - 「iPad 原生横屏 + Apple Pencil 无纸化 + 同步学习 + 离线可用 + 家长管控」组合仍是空档；
   - 监管趋严背景下，启发式答疑、不直接给答案是合规趋势。
3. **用户分层选型建议**：低年级以课本点读/生字/口算为主（对标纳米盒+专项工具）；中高年级需要体系化同步 + 错题闭环（对标学而思/洋葱）；所有年级都缺一个「纸笔体验」级别的无纸化刷题容器（对标 GoodNotes）。

## 五、风险提示

- 教材版权必须提前商务签约；
- 拍照搜题受监管时段限制，需弱化直接给答案；
- 青少年模式、内容审核为合规底线；
- 头部厂商已占据搜题、网课心智，差异化必须落在「iPad 体验 + 同步闭环 + 无纸化」。

# 第二部分 竞品功能拆解 PRD 结构（可直接用于自研 i同步学）

## 1. 产品定位（PRD 第 1 章）

- 产品名称：**i同步学**（英文名 iLearn；完整展示名：i同步学 · 义务教育同步学习）
- 目标用户：小学 1–6 年级 / 初中 7–9 年级
- 核心设备：iPad（横屏优先、Apple Pencil 必适配）
- 核心价值：校内同步 + 作业辅导 + AI 答疑 + 无纸化错题 + 学情闭环
- 差异化：iPad 原生横屏架构 + Pencil 深度手写 + 离线可用 + 无广告 + 强管控

## 2. 功能模块总览（PRD 第 2 章）

| 模块 | 定位 | 关键能力 |
|---|---|---|
| 模块 1 教材同步中心 | 核心 | 版本匹配（人教/苏教/北师大/外研等）、课本点读/跟读/发音评测、预习微课、课时练习、单元复习/知识点导图 |
| 模块 2 AI 作业辅导 | 刚需 | 拍照搜题（整页识别）、AI 启发式讲解（给思路不给答案）、口算/应用题批改、中英文作文批改 |
| 模块 3 错题本系统 | 高价值 | 自动收录、按知识点/年级/学科分类、错题重做、导出 PDF、艾宾浩斯复习计划 |
| 模块 4 AI 答疑辅导 | 辅助 | 文字/语音/拍照提问、知识点讲解、同类题举一反三、学习路径推荐 |
| 模块 5 无纸化学习 | iPad 专属 | PDF 试卷手写答题、Pencil 批注、手写转文字、试卷图层（做题层/答案层分离）、分屏笔记 |
| 模块 6 学情与家长管控 | 必备 | 学习时长统计、薄弱知识点图谱、每日学习报告、远程锁定、搜题权限控制 |
| 模块 7 离线资源包 | 必备 | 教材/微课/试卷/错题离线，断点续传 |
| 模块 8 用户体系 | 基础 | 学生端、家长端、多孩子切换、年级切换 |

## 3. 核心页面结构（可直接画原型）

首页（iPad 横屏大屏仪表盘）→ 同步学习页（教材目录）→ 作业辅导页（拍照按钮居中）→ 错题本页 → 我的学习（学情报告）→ 设置（家长管控）。

## 4. 核心功能详细拆解（每条 = 可开发）

### 4.1 拍照搜题 / 作业批改（对标作业帮 / 小猿）

- 拍摄：单题 / 整页 / 连拍；图像增强：暗光、阴影、褶皱矫正；手写识别兼容小学生潦草字；
- 题库匹配 100ms 内返回；返回结果：知识点、思路引导、步骤讲解、同类题 3 道；
- 管控：家长可设置「不显示答案」。

### 4.2 教材点读（对标纳米盒）

- 课本图片可点读、分句播放、跟读打分、语速调节、离线音频包。

### 4.3 微课学习（对标洋葱学园）

- 5 分钟动画微课、视频内互动答题、看完即练、断点续播、离线下载。

### 4.4 错题本（所有头部产品标配）

- 自动抓取：从搜题 / 练习 / 试卷收录；标签体系：知识点 ID 体系（必须自建）；
- 一键重练、错题重测、导出 A4 试卷 PDF。

### 4.5 Apple Pencil 手写（iPad 核心竞争力）

- 压感笔迹、笔迹平滑、手写擦除、框选/移动/缩放、手写转文字、手写答案识别上传。

### 4.6 家长管控（教育 App 必备合规）

- 使用时长限制、夜间禁用、搜题开关、付费验证、学习周报推送。

## 5. 非功能需求（PRD 必写）

- 支持 iPad 全机型（iPad 9 代及以上）；横屏自适应；内存占用 < 300MB；启动时间 < 1.5s；
- 离线资源包大小可控（单课本 ≤ 500MB）；支持断点续传；
- 青少年模式合规；内容安全审核。

## 6. 数据埋点核心指标

首页打开率、搜题次数/天、微课完播率、错题重做率、Pencil 使用时长、分屏使用占比、离线使用占比、家长绑定率。

# 第三部分 自研 App 适配 iPad：架构层必须实现的能力

## 1. iPad 横屏架构（必须从底层支持）

- 必须：iPad 原生布局（不用 iPhone 拉伸）；支持 Split View 分屏（1/2、1/3、2/3）；支持台前调度（Stage Manager）；横竖屏自动切换不崩溃；大屏仪表盘布局（左侧导航 + 右侧内容区）。
- 技术关键点：AutoLayout + SizeClass；单独为 iPad 建一套 UI 结构；支持多窗口（iPadOS 15+）。

## 2. Apple Pencil 手写架构（核心竞争力）

- 4 大能力：笔迹绘制（压感、倾斜、粗细）、手写识别（文字/公式/图形）、手写答案上传（主观题）、PDF 批注图层（不破坏原文档）。
- 架构方案：底层用 iOS 原生 PencilKit；笔迹矢量保存（不存图片，省空间）；手写转文字集成第三方（百度 AI 教育笔 / 有道 OCR）或自研。

## 3. 离线资源架构（iPad 学习产品必备）

- 资源分包：教材/微课/试卷/音频独立分包；断点续传；下载队列管理；存储智能清理；离线不降权。
- 存储结构：`Documents/离线资源/版本/年级/学科/课本ID`；数据库用 Realm 或 SQLite；资源加密防盗版。

## 4. 多端同步架构（iPad ↔ iPhone ↔ 家长小程序）

- 同步内容：学习记录、错题本、收藏、学习计划、学情数据、家长设置。
- 方案：云端增量同步（不同步全量）；WiFi 自动同步、流量下提示；离线修改 → 上线自动合并；云端用教育专区云服务；数据协议 Protobuf 或 JSON。

## 5. 分屏、多任务、台前调度架构

- 必须支持：一边网课/微课、一边笔记/答题；拖拽文字/图片到笔记；分屏拍照搜题不闪退。
- 关键点：生命周期独立管理；不依赖单 ViewController；多窗口数据隔离但可互通。

## 6. 图像识别架构（拍照搜题/批改）

- 能力：图像矫正、手写印刷体混排识别、公式识别、作文切题、错题区域检测。
- 推荐：前端相机采集 + 图像处理；后端教育 OCR + 题库检索；本地轻量模型提升离线体验。

## 7. 家长管控与合规架构

- 从底层嵌入：功能开关远程配置、时间锁、夜间禁用、内容过滤、支付密码验证、日志上报（家长端可见）。

# 第四部分 完整版 PRD｜i同步学（iPad 端）

## 文档信息

- 文档名称：**i同步学（iLearn）** V1.0 PRD（iPad 义务教育同步学习版）
- 产品形态：iPadOS 原生 App，支持 iPhone 兼容，优先保障 iPad 横屏体验
- 核心主线：教材同步【预习 → 微课学习 → 随堂练习 → 单元测评 → 错题复盘】
- 排除定位：不以拍照搜题为核心流量入口，搜题仅作辅助答疑工具，支持家长一键关闭

## 1. 产品概述

### 1.1 产品目标

围绕国内义务教育各版本教材，搭建完整校内同步学习链路；依托 iPad 大屏与 Apple Pencil 实现电子化学习、纸笔式答题；构建学生自主学习 + 家长学情监控体系。

### 1.2 用户角色

- 学生端（主角色，iPad 操作）：课前预习、看同步微课、做习题、整理错题、课本点读
- 家长端（App 内切换 / 微信小程序联动）：查看学情、配置学习权限、设置时长管控

### 1.3 运行环境

iPadOS 16.0 及以上；支持全系 iPad；兼容 Split View 分屏、台前调度 Stage Manager；深度适配 Apple Pencil 一代/二代。

### 1.4 核心约束（合规前置）

- 严格落实青少年模式；
- 答疑优先启发式讲解，可配置禁止直接展示完整答案；
- 所有音视频、教材内容具备版权资质；
- 支持无网络离线学习。

## 2. 全局产品架构模块（顶层模块）

账号与多角色中心；教材同步中心（核心主线）；课程微课学习模块；习题测评模块；AI 学习答疑模块（辅助）；无纸化纸笔学习模块（iPad 差异化核心）；智能错题本 & 知识图谱模块；学情分析与家长管控模块；离线资源管理模块；消息与学习计划模块。

## 3. 各模块详细功能需求

### 模块 1：账号与多角色中心

- 手机号注册登录，家长绑定多个学生账号，快速切换年级、学科、教材版本；
- 青少年模式自动触发，未完成实名认证开启功能限制；
- 多端数据同步开关（流量 / WiFi 策略配置）；
- 个人信息：年级、地区、教材版本（核心基础数据，影响同步内容分发）。

### 模块 2：教材同步中心【核心模块】

对标：纳米盒、学而思同步板块。

- 教材库管理：覆盖人教、北师大、苏教、外研等主流版本；语数英物化生政史地；按【学段 → 年级 → 学科 → 版本】筛选；
- 电子课本：高清分页、iPad 横屏双页仿真课本；语文/英语课本点读、分句音频、复读、跟读 AI 发音评测；支持 Pencil 手写批注、划线标记；
- 课时目录体系：每课时统一资源包【预习导学 → 同步微课 → 随堂练习 → 知识点卡片 → 拓展阅读】；
- 学习进度自动记录：读到哪一页、微课第几秒、习题完成状态云端同步。

### 模块 3：课程微课学习模块

对标：洋葱学园、学而思同步微课。

- 同步微课：5–8 分钟轻量化知识点动画/实录微课，匹配教材课时；
- 视频交互：播放中途弹随堂小题；断点续播、倍速调节、字幕开关；支持离线下载；
- 知识点锚点：视频内可点击跳转对应习题、错题本相关题目；
- 学习埋点：完播率、中途退出、互动答题正确率。

### 模块 4：习题测评模块

- 分层习题体系：基础巩固 → 能力提升 → 单元综合测评；
- 题型：选择、填空、判断、简答、计算、作文、听力；
- 两种答题模式：触屏答题；Apple Pencil 纸笔手写答题（iPad 核心交互）；
- 自动批改：客观题即时批改，主观题 AI 辅助批改 + 参考答案；
- 试卷导出：单元测评可导出 PDF，支持打印或无纸化二次作答。

### 模块 5：AI 学习答疑模块（辅助，非核心）

- 三种提问方式：文字输入、拍照上传题目、截图提问；
- 输出策略（家长可配置）：模式 A（宽松）思路+分步解析+参考答案；模式 B（推荐/默认）仅启发式提问引导，不直接展示完整答案；
- 自动关联：提问题目绑定对应课时微课、同类练习题；
- 管控开关：家长可完全关闭 AI 答疑。

### 模块 6：无纸化纸笔学习模块【iPad 差异化核心】

对标 GoodNotes 学习体验，内置轻量化能力，无需跳转第三方 App。

- PDF/电子试卷导入、电子课本批注；
- Apple Pencil 完整能力：压感笔迹、橡皮擦、套索移动笔迹、文字高亮；
- 双层试卷架构（关键功能）：底层原题试卷，上层手写作答图层，独立答案图层可隐藏/显示；
- 手写识别：手写文字、数学公式识别，支持转文本；
- 笔记归档：按学科、课时归档，支持同步云端。

### 模块 7：智能错题本 & 知识图谱模块（高留存模块）

- 错题来源：随堂练习、单元测评、AI 答疑题目；
- 自动标签绑定：知识点唯一 ID、学科、年级、错误类型（概念不清/计算失误/审题错误）；
- 错题操作：重做错题、添加个人笔记、同类题推送；
- 复习规划：基于艾宾浩斯生成定期错题复习任务；
- 知识图谱可视化：大屏展示薄弱知识点，推荐对应同步微课。

### 模块 8：学情分析与家长管控模块

- 学生端：每日学习报告、学习时长、习题正确率、薄弱知识点汇总；
- 家长能力：远程查看每日/每周学情报表；设置每日可用时长、夜间禁用时段；功能开关（AI 答疑、离线下载权限）；异常学习提醒（长时间刷题、频繁提问）；学习周报支持 PDF 导出。

### 模块 9：离线资源管理模块

- 资源颗粒度：整本教材、单个课时、单个微课独立下载；
- 下载队列、断点续传、文件完整性校验；
- 存储空间智能提醒、一键清理缓存/闲置资源包；
- 离线可用：课本浏览、本地笔记、已下载微课、本地错题复习、本地习题作答；联网后增量同步。

### 模块 10：消息与学习计划模块

- AI 自动生成每日同步学习计划（预习-听课-练习），可手动调整；
- 学习任务提醒、错题复习提醒；
- 学习勋章激励体系（轻量化，避免游戏化过重）。

# 第五部分 自研 App 适配 iPad｜架构层完整能力方案

## 整体架构分层

前端（iPad 客户端）→ 网关层 → 业务服务层 → AI 能力中台 → 资源中心 → 数据同步服务 → 数据库

## 1. UI 多任务底层架构（重中之重）

- SizeClass + AutoLayout 双方案；独立一套 iPad 大屏布局，不复用 iPhone UI；区分紧凑宽度（手机）、常规宽度（iPad 横屏）；
- 多任务支持：Split View（1/2、1/3 分屏）页面动态重排；台前调度窗口缩放自适应；横竖屏平滑切换不销毁当前页面（正在做试卷不强制刷新）；
- 生命周期优化：分屏前后台频繁切换时缓存阅读位置、答题草稿、笔迹，防止数据丢失。

## 2. Apple Pencil 手写架构（产品核心壁垒）

- 技术选型：底层原生 PencilKit（首选，延迟最低、系统级压感倾斜支持），上层封装自研笔迹管理器；
- 矢量笔迹存储：不存图片，存点坐标、压力、时间戳，降低同步带宽与本地存储；
- 双图层渲染：底层静态文档（课本/PDF），上层可交互笔迹图层，独立答案图层；
- 手写识别两条路线：在线服务端教育 OCR（公式、中文手写）；本地轻量化端侧模型（离线简单手写）；
- 笔迹同步：增量同步，只上传新增笔迹，不整页同步。

## 3. 离线资源调度架构

1. **资源分层**：元数据（目录、知识点信息）→ 教材资源（PDF/图片）→ 媒体资源（微课/音频，按课时分包）→ 题库资源（题目/答案解析，可增量更新）；
2. 下载管理器：队列 + 断点续传 + 完整性校验（MD5/分块校验）+ 失败重试；
3. 存储策略：Documents 分级目录（版本/年级/学科/课本ID），LRU 清理，家长可一键清理缓存；
4. 离线优先：启动时读本地资源，联网后台增量同步版本差异，弱网不阻塞。

## 4. 数据同步架构【补全】

1. 增量同步引擎：以「操作日志」为同步单元（学习记录、错题新增/删除、笔迹、收藏），不整库同步；
2. 冲突策略：按「最近修改时间 + 客户端设备优先级」合并；错题等关键数据双端合并去重；
3. 通道策略：WiFi 自动同步；蜂窝网络仅同步文本类（记录/错题/设置），媒体类提示后下载；
4. 离线队列：离线产生的写操作先落本地队列，联网后按序推送，服务端回执确认后清理。

## 5. 图像识别与 AI 能力中台【补全】

1. 能力编排：图像矫正 → 版面分析 → 手写/印刷识别 → 结构化输出 → 题库/AI 匹配；
2. 模型分层：端侧轻量模型（手写数字、口算、简单公式）优先，复杂任务走服务端；
3. 题库检索：知识点 ID + 题干相似度双路召回，超时降级返回启发式讲解；
4. 合规开关：答案展示由家长配置下发，服务端与客户端双重校验。

## 6. 家长管控与合规架构【补全】

1. 管控配置中心：每日时长、夜间禁用、搜题/AI 开关、离线下载权限，家长端修改后增量下发；
2. 强制逻辑：时长上限在客户端本地强制执行（防绕过），异常上报（长时间刷题、频繁提问）；
3. 数据合规：最小化采集、学习数据加密存储、青少年模式默认开启、内容安全审核流水线。

# 第七部分 iPad 专属交互规范【补全】

> 原帖承诺该交付项但生成中断，以下按「左侧导航 + 右侧内容区」大屏规范补全。

## 1. 通用布局

- 左侧固定导航（宽 280–320pt）：首页、教材库、错题本、笔记、学情、设置；右侧为内容区，内容区最大宽度 1024pt，居中留白；
- 导航图标 + 文字双显示，选中态高亮；横竖屏切换时导航可折叠为图标栏。

## 2. 触控与 Pencil 双输入

- 所有可点元素最小 44×44pt；习题页默认触屏模式，铅笔图标一键切换 Pencil 模式；
- Pencil 模式下：掌心可落屏（防误触），笔迹 0 延迟渲染，双指滚动/缩放，三指撤销；
- 手写识别结果以「可编辑文本」形式悬浮，支持一键替换笔迹。

## 3. 电子课本与试卷

- 双页仿真翻页；点读区域热区 ≥ 40pt；长按弹出批注工具栏（高亮/划线/文字）；
- 试卷图层：答题层与答案层分别显隐，「对答案」按钮一键切换，防止先看答案。

## 4. 反馈与状态

- 所有提交类操作即时反馈（toast + 音效可选）；加载用骨架屏不用菊花；
- 错误状态给出「重试/离线可用」双选项，不出现空白页。

## 5. 青少年模式视觉

- 柔和配色、大字号（正文 ≥ 17pt）、无弹窗广告；夜间自动切换深色护眼模式。

# 第八部分 知识点 ID 体系标准设计（教育产品核心资产）【补全】

> 原帖承诺该交付项但生成中断，以下按教育 App 通用标准补全。

## 1. ID 规则

统一编码：`学段(1) + 学科(2) + 年级(2) + 教材版本(2) + 册次(1) + 单元(2) + 课时/知识点序号(2)`

示例：`P_SX_03_RJ_A_02_05`（小学·数学·三年级·人教版·上册·第二单元·第 5 知识点）。

## 2. 知识点分级

| 层级 | 定义 | 示例 |
|---|---|---|
| L1 学科 | 语/数/英/科… | SX |
| L2 领域 | 数与代数/图形与几何… | ND |
| L3 单元知识点 | 教材单元内最小讲授单位 | 两位数乘两位数 |
| L4 考点/题型 | 考查形式与易错点 | 进位处理、末尾有 0 |

## 3. 错题标签结构

每条错题至少绑定：知识点 ID（L3 必填）+ 学科 + 年级 + 错误类型（概念不清/计算失误/审题错误）+ 来源（随堂/测评/答疑）+ 时间戳。

## 4. 数据资产化

- 知识点 ID 同时驱动：教材目录、微课锚点、题库标签、错题归类、知识图谱、推荐系统；
- 建立「知识点掌握度」模型：按 最近作答时间 × 正确率 × 重做次数 加权，输出薄弱点 Top 10；
- 换教材版本时通过「知识点映射表」迁移，不丢历史错题。

## 一、整体结论

1. **市场定位成立**：义务教育 iPad 端「原生横屏 + Pencil 无纸化 + 校内同步 + 错题闭环 + 家长管控」仍是差异化空档；
